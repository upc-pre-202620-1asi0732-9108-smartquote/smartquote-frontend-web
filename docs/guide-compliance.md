# Web requirements alignment

Source: upc-pre-202620-1ASI0732-final_project-statement-abet_v1, supplied project statement, printed page 35 for technology and languages.

| Requirement | Web implementation |
| --- | --- |
| Vue and JavaScript, HTML5 and CSS3 | Vue single-file components with JavaScript, Vite entry and CSS |
| PrimeVue with Material Design | PrimeVue with the Material preset from @primeuix/themes |
| English default and Latin American Spanish | en_US and es_419 translations, persisted language selection |
| Accessibility | Headings, form labels, explicit selector names, keyboard controls, skip link and feedback |
| Domain-driven architecture | Business contexts with domain, application, infrastructure and presentation |
| Backend integration | REST endpoints with JWT, expectedVersion and backend comparison results |
| GitFlow and conventional commits | develop integration and feature/release/hotfix workflow documented in README |
| Terms footer | Bilingual operational terms dialog; content requires project-owner review |

This maps frontend features. It does not assert complete compliance with all academic deliverables or a formal accessibility audit. The native mobile application, academic report and backend changes are separate deliverables. The web layout adapts to narrow browser windows.
